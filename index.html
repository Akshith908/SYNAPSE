    Designed like a demo-ready neuroinformatics console instead of a single scrolling prototype.

    This version separates the project into focused views so you can present the concept, run the simulation, explain disease differences, and revisit past configurations without losing context.

    Why Multipage

    Each view supports a different part of your presentation.

    • Overview introduces the concept and current disease state.
    • Explorer is where the interactive simulation actually happens.
    • Disease Lab explains why the selected condition looks different.
    • History restores previous configs so you can demo repeatable scenarios.

    Believability Layer

    Fake data, but with consistent network-specific behavior.

    • Every condition now changes visual tone, affected circuits, and matrix structure.
    • Metrics, region emphasis, and edge attenuation are aligned to the disease narrative.
    • Restored history entries replay those settings instead of only showing a text summary.
